## What this agent does
A 5-agent system that runs on real Instagram data (pulled via Apify) and reports to Telegram:

1. **Ideator** — scouts content ideas from what's working for us and competitors
2. **Hook & Script** — turns ideas into hooks + short scripts
3. **Planner** — lays out a daily content calendar
4. **Analyst** — tracks our stats vs. competitors, surfaces top/underperforming posts
5. **DM Manager** — handles inbound DMs (drafts replies / flags ones needing a human)

## Data rules
- Real data only — pulled from Apify's `instagram-scraper` actor (resultsType: posts), never the
  `instagram-profile-scraper`'s `latestPosts` field (it only returns recent posts and misjudges
  true top posts).
- Data lives in `dashboard/data.json`, regenerated by `scripts/pull-data.js`.
- Secrets live in `.env` (gitignored) — never printed, never committed.

## Folder map
- `scripts/` — data-pulling and automation scripts (Node)
- `dashboard/` — the dashboard (index.html + JS) and `data.json`
- `.env` — API tokens (Apify, Telegram) — gitignored, never committed
